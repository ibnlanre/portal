All stores share the same core API surface.

## $get()

```ts
const store = createStore({ count: 0 });

store.$get(); // { count: 0 }
store.count.$get(); // 0
```

## $set()

Set a new value, or pass an updater function.

```ts
store.count.$set(1);
store.count.$set((prev) => prev + 1);
```

For object-like stores, `$set` performs partial updates (deep merge) by default.

## $subscribe(subscriber, immediate?)

```ts
const unsubscribe = store.$subscribe((state) => {
  console.log("state:", state);
});

unsubscribe();
```

- `immediate` defaults to `true`
- pass `false` to skip the initial call

## $use()

React hook for reading/updating store values.

```tsx
const user = createStore({ name: "Alex" });

function Profile() {
  const [name, setName] = user.name.$use();
  return <input value={name} onChange={(e) => setName(e.target.value)} />;
}
```

## $at(path)

Select a nested store by a dot-delimited path.

```ts
const store = createStore({
  user: { preferences: { theme: "light" as const } },
});

store.$at("user.preferences.theme").$get();
store.$at("user.preferences.theme").$set("dark");
```
