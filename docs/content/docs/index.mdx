`@ibnlanre/portal` is a state-management library for React applications whose
state has structure. Start from one root store, then read, update, subscribe to,
or use the branch a feature actually owns.

It gives you:

- One store API at the root and at every nested branch
- Direct property access when the path is known, and `$at()` when it is dynamic
- Type inference from the value used to create the store

## Install

```bash
pnpm add @ibnlanre/portal
```

## Start with a branch

```ts
import { createStore } from "@ibnlanre/portal";

const app = createStore({
  user: {
    profile: {
      name: "Taylor",
      preferences: { theme: "light" },
    },
  },
});

const preferences = app.$at("user.profile.preferences");

preferences.theme.$set("dark");
console.log(preferences.$get()); // { theme: "dark" }
```

## Two ways to reach the same store

```ts
import { createStore } from "@ibnlanre/portal";

const user = createStore({
  profile: {
    name: "Alex",
    preferences: { theme: "light" },
  },
});

user.profile.name.$set("Taylor");
user.$at("profile.preferences.theme").$set("dark");
```
