A function in a `composite` shape stays a method, exposed as written, and is not
state. Write it next to the branches it changes and refer to the store variable
directly.

```ts
import { composite, primitive } from "@ibnlanre/portal";

const counter = composite({
  count: 0,
  step: primitive(1),
  increment() {
    counter.count.$set((count) => count + counter.step.$get());
  },
  reset() {
    counter.$reset();
  },
});

counter.increment();
```

`counter.$get()` is `{ count: 1, step: 1 }`: methods are not part of the state.
To share methods across stores, spread the parts into the shape:

```ts
const state = { count: 0 };
const actions = { log: () => console.log("hi") };
const store = composite({ ...state, ...actions });
```

## Async actions

Methods can be async; write to the branches when the work completes.

```ts
const notifications = composite({
  items: primitive<string[]>([]),
  loading: false,
  async load() {
    notifications.loading.$set(true);
    const items = await fetchNotifications();
    notifications.$set({ items, loading: false });
  },
});
```
