---
title: Subscriptions
description: Listen to a store, a branch or a collection.
icon: Radio
---

```ts
import { composite } from "@ibnlanre/portal";

const store = composite({ count: 0, user: composite({ name: "A" }) });

const stop = store.$subscribe((state) => console.log(state));
store.count.$set(1);
stop();
```

## Immediate invocation

`$subscribe` delivers the current value at once. Pass `{ immediate: false }` to hear only
changes:

```ts
store.$subscribe(handler, { immediate: false });
```

## Unsubscribing

The returned function removes the subscription and is safe to call twice. A
subscriber whose immediate call throws is removed.

## Who hears a write

A write notifies the written store, its descendants and every composite connected
to it, however far, once per outermost write, even when the value is equal.
Siblings do not hear it. A composite's subscribers hear any change of any
connected store below it; a branch's subscribers hear only that branch and
below. A subscriber is called at most once per outermost write, even when it was
reached along several paths.

```ts
store.user.name.$set("B"); // user, name and the root hear it; count does not
```

A write that touches several branches (a partial `$set` on a composite) is
delivered once to each subscriber, after every branch is updated: a subscriber
never observes a half-applied write.

## Delivery and errors

Delivery is synchronous. A write made by a subscriber is delivered after the
current one, in order. If subscribers throw, the others still run, then the error
is rethrown (several errors arrive together as an `AggregateError`).

## After disposal

A disposed store drops its subscribers. Subscribing to it delivers the current
value once (unless `immediate` is `false`) and registers nothing.
