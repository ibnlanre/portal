```bash
pnpm add @ibnlanre/portal
```

Portal needs React 19 for the hooks. The stores themselves work without React.

## A value: `primitive`

```ts
import { primitive } from "@ibnlanre/portal";

const count = primitive(0);
count.$set((current) => current + 1);
count.$get(); // 1
```

`primitive` takes a value or an initializer, `primitive(() => 0)`. It never
looks inside the value: a write swaps it, and a read returns the very reference
you gave. State a type in one place, the type argument:

```ts
const picked = primitive<null | string>(null); // no cast
```

## A tree: `composite`

```ts
import { composite, primitive } from "@ibnlanre/portal";

const app = composite({
  cart: composite({ items: primitive<string[]>([]) }),
  title: "",
  add(item: string) {
    app.cart.items.$set((items) => [...items, item]);
  },
});
```

Each member is decided by what you wrote. A store becomes that branch. A
function becomes a method. Anything else, including a plain object, becomes a
leaf: a `primitive` made for you. To branch an object, write
`composite({ ... })`.

## Branches by key: `collection`

```ts
import { collection, composite, primitive } from "@ibnlanre/portal";

const drafts = collection((organisation: string) =>
  composite({ lines: primitive<string[]>([]) })
);

drafts("acme").lines.$set(["a"]);
drafts.$has("acme"); // true
drafts.$delete("acme");
```

## In a component

```tsx
function Title() {
  const [title, setTitle] = app.title.$use();
  return <input value={title} onChange={(e) => setTitle(e.target.value)} />;
}
```

| Export         | What it is                                   |
| :------------- | :------------------------------------------- |
| `primitive`    | One whole value.                             |
| `composite`    | A tree of named branches.                    |
| `collection`   | Branches made by key.                        |
| `persist`      | Hydrate and save a store through an adapter. |
| `contextStore` | A store scoped to a React provider.          |
