Want your data to stick around after the user hits refresh? Portal makes it easy to sync your store with LocalStorage, SessionStorage, or any custom backend.

The pattern is always the same:

1. **Get** the saved state (or a default).
2. **Create** the store.
3. **Subscribe** to updates to save changes.

## Local Storage

Use `createLocalStorageAdapter` to persist data in the browser permanently (until cleared).

```ts
import { createStore, createLocalStorageAdapter } from "@ibnlanre/portal";

// 1. Create the adapter
const [get, set] = createLocalStorageAdapter<number>("my-counter-key");

// 2. Initialize store with saved data (or 0 if empty)
const counterStore = createStore(get(0));

// 3. Save changes automatically
counterStore.$subscribe(set, false); // 'false' skips initial save
```

That's it! Your counter now survives reloads.

## Session Storage

If you only want data to persist while the tab is open, use `createSessionStorageAdapter`.

```ts
import { createStore, createSessionStorageAdapter } from "@ibnlanre/portal";

const [get, set] = createSessionStorageAdapter("session-data");

const store = createStore(get({ step: 1 }));

store.$subscribe(set, false);
```

## Cookie Storage

Need your state accessible by the server? Or specifically need cookies? We've got you covered.

**Note:** You can optional sign your cookies with a secret to prevent tampering!

```ts
import { createStore, createCookieStorageAdapter } from "@ibnlanre/portal";

const [get, set] = createCookieStorageAdapter("user-prefs", {
  path: "/",
  secure: true,
  maxAge: 3600 * 24 * 365, // 1 year
  secret: "my-secret-key", // Enables signing!
});

const prefsStore = createStore(get({ theme: "dark" }));

prefsStore.$subscribe(set, false);
```

## Custom Storage

Have a weird use case? Storing data in `AsyncStorage`, `IndexedDB`, or a remote API?

`createBrowserStorageAdapter` (sync) and `createAsyncBrowserStorageAdapter` (async) let you plug in any storage engine.

```ts
import {
  createStore,
  createAsyncBrowserStorageAdapter,
} from "@ibnlanre/portal";

const [get, set] = createAsyncBrowserStorageAdapter("secure-data", {
  async getItem(key) {
    // Your custom logic (e.g., IndexedDB)
    return await myDB.get(key);
  },
  async setItem(key, value) {
    await myDB.put(key, value);
  },

  // Optional: Encrypt before storing!
  beforeStorage(data) {
    return encrypt(data);
  },
  // Decrypt before using
  beforeUsage(data) {
    return decrypt(data);
  },
});

// Use 'await' to get the initial state
const initialState = await get({ sensitive: "default" });
const store = createStore(initialState);

store.$subscribe(set, false);
```
