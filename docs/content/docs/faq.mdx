## Why does my subscriber run immediately?

`$subscribe` calls the subscriber immediately by default so your UI and side effects can initialize from the current state.

If you’re wiring persistence/hydration, pass `{ immediate: false }` as the second argument:

```ts
store.$subscribe(
  (state) => {
    // persist
  },
  { immediate: false }
);
```

## How do I update deep values?

Navigate through properties; every branch is a store you can pass around:

```ts
store.user.preferences.theme.$set("dark");

function Theme({ theme }: { theme: typeof store.user.preferences.theme }) {
  const [value] = theme.$use();
  return <span>{value}</span>;
}
```

For branches made by key, use `collection`:

```ts
const drafts = collection((id: string) => composite({ note: "" }));
drafts("acme").note.$set("hello");
```
