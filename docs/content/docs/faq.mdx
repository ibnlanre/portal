## Why does my subscriber run immediately?

`$subscribe` calls the subscriber immediately by default so your UI and side effects can initialize from the current state.

If you’re wiring persistence/hydration, pass `false` as the second argument:

```ts
store.$subscribe((state) => {
  // persist
}, false);
```

## How do I update deep values?

For composite stores you can either navigate through properties:

```ts
store.user.preferences.theme.$set("dark");
```

…or select by path:

```ts
store.$at("user.preferences.theme").$set("dark");
```

Use dot access when the branch is already known in your feature. Use `$at()`
when the path is dynamic or when you want to pass a focused store boundary to
reusable code.
